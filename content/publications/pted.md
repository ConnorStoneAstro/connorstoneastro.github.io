Two-sample tests are wildly valuable in scientific inference (figure 1 of the paper shows many places to use them in a standard workflow), but are underutilized in many contexts. PTED is a powerful, fast, and easy to use two-sample test code which I demonstrate on a number of toy problems. PTED is an easy to reach for first check, much like a Kolmogorov-Smirnov test is in one dimension.
